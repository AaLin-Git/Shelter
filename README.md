# Shelter

## About:

Shelter is a two page project, responsive and interactive.

## Key skills:

* pixel perfect valid semantic adaptive layout
* easy to maintain readable code
* export styles and graphics from Figma
* using JavaScript to implement the functionality specified in the task

## Added functionality:

* burger menu on both pages
* popup for animal cards on both pages
* infinite carousel slider on main page
* pagination on the pets page
